Animate union and intersection of two sorted linked lists using basic list operations.

Output List union

Case 1 Approach: Union

  1. Use two cursors, one for L1 and one for L2.
  2. Compare the current elements because both lists are sorted.
  3. Insert the smaller value into the output list and advance that cursor.
  4. If both values are equal, insert it once and advance both cursors.
  5. When one list ends, append the remaining elements from the other list.

Case 2 Approach: Intersect

  1. Use two cursors, one for L1 and one for L2.
  2. If the values match, insert the value into the output list and advance both cursors.
  3. If L1 is smaller, advance the L1 cursor.
  4. If L2 is smaller, advance the L2 cursor.
  5. Stop when either list ends.

Running Time

Each cursor only moves forward. For lists of length N and M, both union and intersection run in O(N + M) time. The extra working space is O(1) besides the output list.
