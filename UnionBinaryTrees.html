UnionBinaryTrees

Union two binary search trees, remove duplicates, and build a balanced result tree.

Approach

  1. Build two binary search trees from the input values.
  2. Run inorder traversal on each tree to produce sorted lists.
  3. Merge the two sorted lists and skip duplicates to get the union.
  4. Build the new tree from the sorted union values by choosing the middle value as the root.
  5. Recursively build the left half and right half the same way, which keeps the new tree balanced.

Why The New Tree Is Balanced

The middle value becomes the root, so the left and right subtrees receive almost the same number of nodes. Repeating this for every subtree gives a height-balanced binary search tree.

Pseudocode

UnionTrees(T1, T2):
  A = inorder(T1)
  B = inorder(T2)
  U = mergeUnique(A, B)
  return buildBalanced(U, 0, U.length - 1)

buildBalanced(U, left, right):
  if left > right:
    return null
  mid = floor((left + right) / 2)
  root = new Node(U[mid])
  root.left = buildBalanced(U, left, mid - 1)
  root.right = buildBalanced(U, mid + 1, right)
  return root

Running Time

Let n and m be the sizes of the two trees. Inorder traversal takes O(n + m), merging takes O(n + m), and building the balanced tree takes O(k), where k is the number of unique values. Total time is O(n + m). Extra space is O(n + m) for the sorted lists and result values.
