RadixSort

Sort non-negative integers by processing digits from least significant to most significant.

Current Array digit place: ones
Buckets 0-9 scan index: 0
Output After Pass collect buckets in order

Approach

  1. Find the largest number to know how many digit passes are needed.
  2. Start with the ones digit, then tens, hundreds, and so on.
  3. For each pass, place every number into bucket 0 through 9 based on that digit.
  4. Collect buckets from 0 to 9 to form the array for the next pass.
  5. After the final digit pass, the array is sorted.

Why It Works

Radix sort uses a stable bucket step. Earlier digit order is preserved inside each bucket while later digit places organize the larger groups.

Pseudocode

RadixSort(A):
  max = largest value in A
  place = 1

  while max / place > 0:
    create buckets 0..9

    for each value in A:
      digit = (value / place) % 10
      append value to bucket[digit]

    A = collect buckets 0..9
    place = place * 10

  return A

Running Time

If n is the number of values, d is the number of digit places, and base is 10, running time is O(d(n + 10)), usually written as O(dn). Extra space is O(n + 10) for buckets.
