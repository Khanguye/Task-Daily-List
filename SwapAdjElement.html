SwapAdjElement

Swap adjacent linked-list nodes by changing links only. The data values stay inside their original nodes.

Condition

Do not swap node data. Only redirect the links between nodes.

Case 1 Approach

  1. Let prev be the node before the pair, x be the first node, and y be the next node.
  2. Point prev.next to y. If x is the head, update the head to y.
  3. Point x.next to y.next.
  4. Point y.next to x.

Case 2 Approach

  1. Let before be x.prev and after be y.next.
  2. Connect before.next to y if before exists.
  3. Connect y.prev to before, then y.next to x.
  4. Connect x.prev to y, then x.next to after.
  5. Connect after.prev to x if after exists.

Running Time

After the adjacent pair is found, the swap takes O(1) time because it changes a fixed number of links. If you must search for the pair first, total time is O(N). Extra space is O(1).
