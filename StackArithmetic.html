StackArithmetic

Approach

  1. Split the expression into tokens: numbers, operators, and parentheses.
  2. Push numbers onto the value stack.
  3. Push ( onto the operator stack.
  4. When an operator appears, first apply operators with higher or equal precedence from the operator stack.
  5. When ) appears, apply operators until the matching ( is removed.
  6. After all tokens are scanned, apply remaining operators.
  7. The final value stack top is the answer.

Operator Rule

  • * and / have higher precedence than + and -.
  • Parentheses force the inside expression to be solved first.
  • For this demo, binary operators are left associative.

Pseudocode

Evaluate(expression):
  for each token:
    if token is number:
      values.push(token)
    else if token is "(":
      ops.push(token)
    else if token is ")":
      apply ops until "("
      ops.pop()
    else if token is operator:
      while ops has higher/equal precedence:
        apply top operator
      ops.push(token)

  while ops is not empty:
    apply top operator

  return values.pop()

Running Time

Each token is pushed and popped at most once, so the running time is O(n). The two stacks can hold up to n tokens, so extra space is O(n).
