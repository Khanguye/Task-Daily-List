# AI Animation Algorithms

AI Animation Algorithms is a static website for interactive algorithm and data structure visualizations. Each demo is a standalone HTML page that can be opened directly in a browser, and `index.html` acts as a simple landing page that links to the available animations.

## Live site

Review the HTML pages online: https://khanguye.github.io/AI-Animation-Algorithms/

## Included animations

- Binary tree operations
- Finding an element in a singly linked list
- Gravity environment simulation
- Print lots
- Radix sort
- Reversing a singly linked list
- Stack arithmetic
- Stack data structure
- Swapping adjacent elements
- Three stacks in one array
- Union of binary trees
- Union of linked lists

## How to view

Open `index.html` in a web browser to browse the full list of demos.

You can also open any individual `.html` file directly, such as `BinaryTree.html` or `RadixSort.html`.

## Project structure

- `index.html` - main page that lists the animation demos
- `*.html` - standalone interactive algorithm pages
- `promts/` - prompt notes used to create or describe the demos
- `skill.md` - project skill/instruction notes
