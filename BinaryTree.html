Functions Included

  • insert(value): add a value while keeping BST order.
  • search(value): move left or right until found or null.
  • delete(value): remove a node with 0, 1, or 2 children.
  • inorder(): left, root, right. Produces sorted order.
  • preorder(): root, left, right.
  • postorder(): left, right, root.
  • levelOrder(): visit breadth-first with a queue.
  • min(), max(), height(), size(), clear().

Approach

  1. Every node has at most two children: left and right.
  2. For this demo, the tree is a binary search tree.
  3. Smaller values go left. Larger values go right.
  4. Search, insert, and delete use comparisons to choose a path.
  5. Traversals visit nodes in a specific order and write values to the output row.

Delete Cases

  1. Leaf node: remove it directly.
  2. One child: replace the node with its child.
  3. Two children: replace the node value with its inorder successor, then delete the successor.

Pseudocode

insert(node, value):
  if node == null: return new Node(value)
  if value < node.value:
    node.left = insert(node.left, value)
  else if value > node.value:
    node.right = insert(node.right, value)
  return node

search(node, value):
  if node == null or node.value == value:
    return node
  if value < node.value:
    return search(node.left, value)
  return search(node.right, value)

Running Time

For a balanced tree, search, insert, and delete are O(log n). In the worst case, if the tree becomes a chain, they are O(n). Traversals are always O(n) because every node is visited once. Space is O(h) for recursive calls, where h is tree height.
