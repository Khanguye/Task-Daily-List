ThreeStacksOneArray

Implement three independent stacks inside one fixed-size array by dividing the array into three regions.

One Array 12 slots split into 3 parts
Stack Tops top index per stack
Ready.

Approach

  1. Create one array of size N.
  2. Divide it into three fixed regions, one region per stack.
  3. Keep a separate top index for each stack.
  4. For push, move that stack's top forward and write the value.
  5. For pop, read the top value, clear that slot, and move top backward.
  6. Overflow happens when a stack's top reaches the end of its own region.

Mapping Formula

For stack s, its region starts at s * capacity. The stack can use indexes from start to start + capacity - 1.

Pseudocode

array = new Array(N)
capacity = floor(N / 3)
top[0] = -1
top[1] = -1
top[2] = -1

indexOf(stack, offset):
  return stack * capacity + offset

push(stack, value):
  if top[stack] == capacity - 1:
    error overflow
  top[stack]++
  array[indexOf(stack, top[stack])] = value

pop(stack):
  if top[stack] == -1:
    error underflow
  index = indexOf(stack, top[stack])
  value = array[index]
  array[index] = empty
  top[stack]--
  return value

Running Time

push, pop, and peek are all O(1). The array uses O(N) space. This fixed-region method is simple, but unused space in one stack cannot be shared with another stack.
