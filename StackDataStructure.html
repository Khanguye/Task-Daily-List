Stack Rule

A stack is LIFO: last in, first out. New values are added at the top, and removal also happens at the top.

Operations

Operation Meaning Time
push(x)Add value to top.O(1)
pop()Remove and return top.O(1)
peek()Read top without removing.O(1)
isEmpty()Check whether size is zero.O(1)
isFull()Check whether size reached capacity.O(1)
size()Return number of elements.O(1)
clear()Remove all elements.O(n)

Pseudocode

push(x):
  if isFull(): error overflow
  top = top + 1
  stack[top] = x

pop():
  if isEmpty(): error underflow
  value = stack[top]
  top = top - 1
  return value

peek():
  if isEmpty(): return null
  return stack[top]

Space

The stack stores up to capacity elements, so storage is O(n). Each individual operation uses O(1) extra working space.
