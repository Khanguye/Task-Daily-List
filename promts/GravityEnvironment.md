# Gravity Environment Prompt

Create an HTML page to simulate a gravity environment.

Requirements:

- When the user places an object in the environment, it should behave like an object in a gravity world.
- Mouse down creates an object.
- Mouse hold and drag defines the vector of force to throw the object.
- Mouse release throws the object.
- After mouse release, simulate the object falling.
- Provide an object list so the user can choose different object types instead of only circle and square.
