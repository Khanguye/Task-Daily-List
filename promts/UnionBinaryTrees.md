# UnionBinaryTrees Prompt

Create an HTML page named `UnionBinaryTrees`.

Problem:

- Given two binary trees or binary search trees.
- Write the union of both trees on an HTML page.
- Make sure the new tree is balanced.

Requirements:

- Allow editable input values for Tree A and Tree B.
- Build both input trees visually.
- Traverse both trees to collect values.
- Remove duplicate values.
- Build a new balanced tree from the union values.
- Explain how the balanced tree is created.
- Include pseudocode.
- Explain running time and space complexity.
- Output: animation UI.
