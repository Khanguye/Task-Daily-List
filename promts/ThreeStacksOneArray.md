# ThreeStacksOneArray Prompt

Create an HTML page showing how to implement three stacks in one array.

Requirements:

- Use one shared array.
- Split the array into three regions.
- Keep a separate top index for each stack.
- Demonstrate `push`.
- Demonstrate `pop`.
- Demonstrate `peek`.
- Show overflow and underflow behavior.
- Explain the mapping formula.
- Include pseudocode.
- Explain running time and space complexity.
- Output: animation UI.
