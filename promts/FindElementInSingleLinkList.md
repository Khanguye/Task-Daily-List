# FindElementInSingleLinkList Prompt

Create an HTML page named `FindElementInSingleLinkList`.

Requirements:

- Case 1: nonrecursive search in a singly linked list.
- Case 2: recursive search in a singly linked list.
- Explain each step.
- Compare the running time.
- Explain how big the list can be before recursion may fail or terminate.
- Output: animation UI.
