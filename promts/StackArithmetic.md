# StackArithmetic Prompt

Create an HTML page that uses a stack to solve arithmetic.

Requirements:

- Use stacks to evaluate an arithmetic expression.
- Show a value stack and an operator stack.
- Support operators such as `+`, `-`, `*`, `/`, and parentheses.
- Animate token scanning.
- Include editable expression input.
- Include `Run Animation`, `Step`, and `Reset` controls.
- Provide a full explanation.
- Include operator precedence rules.
- Include pseudocode.
- Explain running time and space complexity.
- Output: animation UI.
