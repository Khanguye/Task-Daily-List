# StackDataStructure Prompt

Create an HTML page to demo a stack data structure with all core operations.

Requirements:

- Demonstrate `push`.
- Demonstrate `pop`.
- Demonstrate `peek`.
- Demonstrate `isEmpty`.
- Demonstrate `isFull`.
- Demonstrate `size`.
- Demonstrate `clear`.
- Show overflow and underflow behavior.
- Show stack top, size, capacity, and current state.
- Include an operation log.
- Explain each operation.
- Include pseudocode.
- Explain running time and space complexity.
- Output: animation UI.
