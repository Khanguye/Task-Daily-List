# ReverseSinglyLinkedList Prompt

Create an HTML page named `ReverseSinglyLinkedList`.

Requirements:

- Case 1: nonrecursive method to reverse a singly linked list in `O(n)`.
- Case 2: reverse a singly linked list in `O(n)` using constant extra space.
- Show pointer movement for `prev`, `curr`, and `next`.
- Explain each approach.
- Include pseudocode.
- Explain running time and space complexity.
- Output: animation UI.
