# PrintLots Prompt

Create an HTML page named `PrintLots`.

Problem:

- Given linked list `L`.
- Given linked list `P`, containing integers sorted in ascending order.
- Write an operation to print elements in `L` at the positions specified by `P`.

Example:

```text
P = 1, 3, 4, 6
display L(1), L(3), L(4), L(6)
```

Requirements:

- Explain the approach.
- Explain the running time.
- Output: animation UI.
