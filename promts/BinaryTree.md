# BinaryTree Prompt

Create an HTML page named `BinaryTree`.

Requirements:

- Implement a binary tree demo page with animation UI.
- Use a binary search tree for ordered operations.
- Include editable input values to build the tree.
- Include a value input for operations.
- Demonstrate `insert`.
- Demonstrate `search`.
- Demonstrate `delete`.
- Demonstrate `inorder` traversal.
- Demonstrate `preorder` traversal.
- Demonstrate `postorder` traversal.
- Demonstrate `level order` traversal.
- Demonstrate `min` and `max`.
- Show tree statistics such as root, size, height, and leaf count.
- Explain all major functions.
- Explain delete cases:
  - leaf node
  - one child
  - two children with inorder successor
- Include pseudocode.
- Explain running time and space complexity.
- Output: animation UI.
