# UnionLinkedList Prompt

Create an HTML page named `UnionLinkedList`.

Problem:

- Given `L1` and `L2`, two sorted lists.

Requirements:

- Case 1: write a procedure to union both lists only using basic list operations.
- Case 2: write a procedure to intersect both lists only using basic list operations.
- Explain the approach.
- Include pseudocode.
- Explain running time and space complexity.
- Output: animation UI.
