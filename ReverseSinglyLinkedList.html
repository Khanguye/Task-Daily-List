ReverseSinglyLinkedList

Reverse a singly linked list by changing links, not by copying values.

Original list head = node 1
Pointers step 0

Case 1 Approach: Nonrecursive Method

  1. Set prev = null and curr = head.
  2. Save next = curr.next before changing the link.
  3. Reverse the current link with curr.next = prev.
  4. Move prev to curr.
  5. Move curr to next.
  6. When curr becomes null, set head = prev.

Case 2 Approach: Constant Extra Space

  1. Use only three references: prev, curr, and next.
  2. Do not create a second list or copy node data.
  3. At each node, save the next link, reverse the current link, then advance the references.
  4. The links are rewired in place until all nodes point backward.
  5. The final prev is the new head.

Running Time

Both cases visit every node exactly once, so the running time is O(n). The algorithm uses a constant number of references, so extra space is O(1).

Important Detail

The node values do not move. The animation changes only the direction of each node's next link.
