PrintLots

Print the elements in linked list L at the positions specified by sorted linked list P.

L current position: 0
P sorted positions
Output printed values

Approach

  1. Keep one pointer on list L and one pointer on list P.
  2. Move through L only once while counting positions.
  3. When the current position equals the next value in P, print that node from L.
  4. Advance the pointer in P and continue scanning L.

Pseudocode

PrintLots(L, P):
  current = L.head
  position = 1
  target = P.head

  while current != null and target != null:
    if position == target.value:
      print current.value
      target = target.next

    current = current.next
    position = position + 1

Running Time

Because P is sorted, the algorithm scans L at most once and scans P at most once. The running time is O(N + M), where N is the length of L and M is the length of P. Extra space is O(1) besides the printed output.
